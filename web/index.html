The Architecture Flaw

Why Prompt-Based Guardrails Fail

Autonomous computer-use agents execute raw clicks and keyboard events. Traditional safety layers read the agent's internal reasoning or tool call traces. When a model is jailbroken or confused, its internal logs report "Optimizing workspace" while its cursor clicks "Drop Production Cluster".

Insecure: Text / Log Inspection

Collusive Information Channel

The guardrail inspects the agent's chain-of-thought. Because the generator and the monitor share the same linguistic channel, prompt injections can disguise destructive clicks as benign maintenance tasks.

Agent reasoning: "Cleaning cache files..."
Monitor verdict: APPROVED (logs look safe)
Result: Database dropped.
Secure: OpticWall Visual Oversight

Out-of-Band Physical Pixel Grounding

OpticWall sits between the agent and the operating system display buffer. It does not read prompt tokens. It evaluates what is physically rendered on screen before the OS dispatches the mouse click.

Screen buffer: "Confirm Database Drop" modal
OpticWall: Destructive UI element grounded
Result: HARD_BLOCK (Action aborted before execution)

Inspect actions inside custom agent code before calling OS click APIs:

from opticwall import OpticWall

wall = OpticWall(device="cpu")
safe, decision, incident = wall.monitor_action(
    current_frame=screenshot,  # PIL Image
    action_type="click",
    selector="button#delete-account"
)
if not safe:
    print(f"Blocked! Risk: {decision.risk_score:.2%}")
