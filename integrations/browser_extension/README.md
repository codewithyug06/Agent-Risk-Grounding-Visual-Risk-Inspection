# OpticWall Browser Extension Plugin

**The Visual Safety Firewall for Autonomous Web Agents (Playwright, Puppeteer, Browser-Use, OpenAI Operator, Claude)**

---

## 30-Second Installation Guide

### Google Chrome / Microsoft Edge / Brave / Opera

1. Open your browser and navigate to:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
2. Enable **"Developer mode"** in the top-right corner.
3. Click the **"Load unpacked"** button in the top-left.
4. Select this folder: `opticwall/integrations/browser_extension`.
5. The **OpticWall Visual Shield** icon will appear in your browser toolbar!

## How It Protects You

- Automatically intercepts button clicks from autonomous AI agents and automation scripts.
- Evaluates actions against destructive, financial, and privacy-leak risks.
- If a computer-use agent tries to click *"Pay Now"*, *"Drop Database"*, or *"Export PII"*, OpticWall stops execution and prompts for your explicit confirmation.
